# Бот rufivo (aiogram 3.x)

Личный Telegram-бот от лица rufivo: главное меню с фото-обложкой, режим
диалога с ИИ, меню поддержки и полноценная админ-панель.

## ⚠️ Важно про безопасность

Токен, который ты присылал в переписке, нужно считать засвеченным.
Зайди к **@BotFather → /mybots → выбери бота → API Token → Revoke**,
получи новый токен и впиши его только в `.env` (см. ниже). Никогда не
храни токен прямо в коде или в чатах.

## Установка

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Настройка

1. Скопируй `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```
2. Заполни `.env`:
   - `BOT_TOKEN` — новый токен от @BotFather
   - `ADMIN_ID` — твой Telegram ID (6101459866)
   - `ADMIN_USERNAME` — юзернейм без @ (rufivo)
   - `OPENAI_API_KEY` — ключ для режима "Задать вопрос" (если не указать,
     бот всё равно будет работать, но в диалоге честно скажет, что ИИ
     временно недоступен)
3. Положи файл обложки `photo.jpg` в корень проекта (рядом с `bot.py`).

## Запуск

```bash
python bot.py
```

## Структура проекта

```
rufivo_bot/

├── states.py            # FSM-состояния (режим диалога)

│   ├── user.py          # главное меню, "Кто я", диалог, поддержка
│   └── admin.py         # /admin, статистика, юзеры, история, /broadcast
├── requirements.txt
├── .env.example
└── photo.jpg             # добавь сюда свою обложку
```

## Функционал

**Главное меню** (/start):
- 🙋‍♂️ Кто я
- 💬 Задать вопрос — включает диалог с ИИ, отвечающим от лица rufivo
- ✉️ Связаться лично — прямая ссылка на профиль
- 💎 Поддержать — Stars / UAH / Крипта

При переходах между разделами обложка не пропадает — бот редактирует
`caption` того же сообщения с фото.

**Админ-панель** (`/admin`, только для `ADMIN_ID`):
- 📊 Статистика: кол-во пользователей и сообщений в базе
- 👥 Список пользователей с пагинацией → история переписки (15 последних сообщений)
- 🗒 Общие последние логи по всем пользователям
- `/broadcast <текст>` — рассылка всем пользователям из базы

**Надёжность:**
- Сброс зависших апдейтов (`delete_webhook(drop_pending_updates=True)`) при старте
- Все `callback.answer()` обёрнуты от ошибки "query is too old"
- Текст сообщений явно приводится к UTF-8 перед сохранением/отправкой в ИИ
